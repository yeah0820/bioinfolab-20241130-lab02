## 2-2. 나. 검색

대소문자 설정시: 399 result in 1 file
대소문자 미설정시: 400 result in 2 files
 
완전한 단어: 386 result in 2 files
완전하지 않은 단어: 400 result in 2 files

399 400 다르다
이유: 대소문자 구분, 완전한 단어 구분 외에 단어를 검색하는 옵션이 다른 명령어일 것이다.
